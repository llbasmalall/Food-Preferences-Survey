# Food Preferences Survey
[![Ask DeepWiki](https://devin.ai/assets/askdeepwiki.png)](https://deepwiki.com/llbasmalall/Projects/tree/87e8d07d6351576adf4f2d2ea5bf0f9ba0f8c4ba/Survey%20Methodology)

## Overview

This repository contains the methodology and results of a survey conducted to understand food preferences, dietary habits, and consumer behavior. The project includes the raw dataset of responses and a presentation summarizing the findings.

## Project Contents

*   `responses.csv`: The complete dataset containing all the responses gathered from the survey participants.
*   `Food Prefrences.pptx`: A PowerPoint presentation that provides a visual analysis and summary of the key insights from the survey data.

### Dataset: `responses.csv`

The `responses.csv` file is the core of this project, containing detailed information on a wide range of topics related to food. The dataset includes the following columns:

-   **Demographics**: `Gender`, `Age`, `Education`, `Monthly_Income`
-   **Dietary Profile**: `Food Regime`, `Diet` (Healthy/Non-Healthy), `Food_Allergies`, `Salt_Amount`, `SpicyFood`
-   **Meal Preferences**: `Preferred_Meal_Aday`, `Preferred _Breakfast`, `Regular_lunchFood`, `Preferred_Dinner`
-   **Cuisine & Ingredient Preferences**: `Favourite_Cuisine`, `Favourite_Chef`, `Country_Famous_Foods`, `EatingVarious_Vegetables/Fruits`, `Preferred_Vegetables_or_Fruits`, `Disliked_ingredients`
-   **Consumption Habits**: `Shopping_Food`, `FastFood_Consumption`, `Consumed_FastFood`, `Favourite_Restaurant`, `Reason_BuyingFastFood`, `Preferred_Dessert`, `Preferred_Drink`
-   **General**: `Timestamp`, `Name`, `LovingFood`, `OneMeal_Forever`

### Presentation: `Food Prefrences.pptx`

This presentation file contains the analysis and visualization of the data collected in the survey. It highlights key trends, patterns, and conclusions drawn from the respondent data, offering a clear and concise summary of the project's findings.

## Usage

This dataset can be utilized for various purposes, including:
-   Exploratory data analysis (EDA) to identify patterns in food consumption.
-   Market research to understand consumer preferences in the food industry.
-   Academic research on dietary habits and their correlation with demographic factors.
-   Data visualization practice to create insightful charts and graphs from survey data.
